How it works

  1. 1Readcode PyMuPDF pulls every word and its exact position out of the PDF. No model involved.
  2. 2ExtractLLM A model reads the pages and returns fields, each with the exact quote it relied on.
  3. 3Verifycode Code finds every quote on the page, checks dates and amounts, and scores confidence itself. The model's own confidence is ignored.
  4. 4Decidecode Plain code turns verified fields into deadlines, dollar impacts and obligations. No model involved.
  5. 5ActLLM drafts, you approve A model drafts reminders and emails, but code fills in every number and date. Nothing happens until you approve, and nothing is ever sent.
